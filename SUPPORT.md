# Support

Dust Compass is an independent, unofficial map and guide for Black Rock City. It is not affiliated with Burning Man Project, and it is not an emergency, dispatch, medical, ranger, or operational service.

## Choose the right channel

| Need | Where to go | What to include |
| --- | --- | --- |
| Bug report | [GitHub Issues](https://github.com/lnorton89/dustcompass/issues) | Steps to reproduce, expected and actual behavior, browser/device, selected data year, and screenshots if they contain no sensitive locations. |
| Setup or usage question | [GitHub Issues](https://github.com/lnorton89/dustcompass/issues) | What you are trying to do, the command or screen involved, and the exact error message. |
| Feature request | [GitHub Issues](https://github.com/lnorton89/dustcompass/issues) | The problem to solve and why it would help people using the app offline on playa. |
| Security issue | [SECURITY.md](SECURITY.md) | Follow the private-contact process there; do not disclose details publicly. |
| Operational or emergency issue | Official Burning Man and local emergency channels | Do not rely on this app for urgent help, safety decisions, or directions during an emergency. |
| Data correction | [GitHub Issues](https://github.com/lnorton89/dustcompass/issues) | A public source link, the selected data year, the record or map area, and the proposed correction. |

## Before filing an issue

- Check that you are using the intended data year and have refreshed the app while online.
- For local development, run the relevant command from the [README](README.md) and include its output with secrets removed.
- Search existing issues to avoid duplicates.
- Never post API keys, device location history, saved places, personal information, or embargoed locations.

## Data corrections and embargoes

Dust Compass builds its map from published annual survey and listing data. For a correction, link to the public authoritative source whenever possible. Do not request publication of coordinates, addresses, or event locations that have not been officially released; the project intentionally honors location embargoes.

## No emergency support

For medical, safety, law-enforcement, evacuation, or on-playa operational concerns, contact official Burning Man or local emergency resources directly and follow posted instructions. Information in this app can be incomplete, outdated, or unavailable offline; it must not be treated as emergency guidance.
